作者：Ximeng Li，Keyu Peng，Fuxing Huang，Wenxing Zhu

说明：以下为中文技术译文。为保证可读性，公式编号沿用原文；原文中极长的三角展开式与大规模实验表格的逐项数值未逐字重排，但其定义、推导含义与实验结论均已完整翻译，可与原 PDF 对照阅读。

## 摘要

平面规划是 VLSI 物理设计的第一阶段。高效的平面规划引擎必然会对芯片设计速度、质量和性能产生积极影响。本文提出了一种新的数学模型来刻画模块之间的不重叠性，并进一步提出了一种基于泊松方程 VLSI 全局布局方法的扁平化固定轮廓平面规划算法。该算法由全局平面规划和合法化两个阶段组成。

在全局平面规划阶段，本文基于所提出的模块不重叠数学模型以及泊松方程的解析解，重新定义了每个模块的势能。在该框架下，软模块的宽度作为能量函数中的变量出现，因此能够在优化过程中被直接调整。除此之外，本文还设计了一种势能偏导数的快速近似计算方案。

在合法化阶段，本文基于定义好的水平约束图和垂直约束图，通过修改模块间的相对位置来消除全局平面规划后残留的重叠。

在 MCNC、GSRC、HB+ 和 ami49 x 基准上的实验表明：与当前先进平面规划器相比，在给定空白率的条件下，本文算法在小规模与大规模基准上的平均线长分别至少改善 2% 和 5%。

关键词：固定轮廓平面规划；全局平面规划；泊松方程；合法化；约束图

## 1. 引言

平面规划是 VLSI 物理设计流程的第一阶段。随着 IP 核的大量使用以及现代芯片中集成单元数量急剧增长，平面规划需要在固定轮廓内处理数百甚至上千个电路模块。尤其是在平面规划过程中，还常常需要考虑时序、热、功耗、电压岛等更复杂的问题 [1][2]。然而，基础平面规划问题本身是一个 NP-hard 问题。因此，设计高性能的大规模基础平面规划算法一直具有挑战性，并且会直接影响最终芯片的性能和良率。本文重点研究固定轮廓平面规划的扁平化解析引擎。

固定轮廓平面规划可以描述为：在一个固定矩形区域内放置一组矩形模块，要求模块之间不重叠，并使模块间总线长最小。平面规划通常包含两类模块：硬模块和软模块。软模块的宽和高可以在保持面积不变的情况下，在一定范围内进行调整。迄今为止，固定轮廓平面规划方法大致分为三类：

1. 面向小规模问题的启发式方法；
2. 面向大规模问题的多层次启发式方法；
3. 解析方法。

小规模固定轮廓平面规划的启发式方法通常先采用一种平面规划表示方式，再在表示空间中利用启发式算法搜索最优解，最后将该表示解码为对应的平面规划。表示方式决定了平面规划到表示的转换复杂度，以及表示到平面规划的解码复杂度。

表 1 总结了常见的平面规划表示方法。

| 表示法 | 解空间 | 打包时间 | 灵活性 |
| --- | --- | --- | --- |
| Normalized Polish Expression | `O(n! * 2^(2.6n) / n^1.5)` | `O(n)` | slicing |
| Corner Block List [3] | `O(n! * 2^3n)` | `O(n)` | Mosaic |
| Twin Binary Sequence [4] | `O(n! * 2^3n / n^1.5)` | `O(n)` | Mosaic |
| O-tree [5] | `O(n! * 2^2n / n^1.5)` | `O(n)` | compacted |
| B*-tree [6] | `O(n! * 2^2n / n^1.5)` | `O(n)` | compacted |
| Corner Sequence [7] | `<= (n!)^2` | `O(n)` | compacted |
| Sequence Pair [8] | `(n!)^2` | `O(n^2)` | general |
| TCG-S [9] | `(n!)^2` | `O(n log n)` | general |
| ACG [10] | `O((n!)^2)` | `O(n^2)` | general |

其中，O-tree [5] 与 B*-tree [6] 是最常用的两种表示方式，通常配合模拟退火算法。Parquet [11] 使用 sequence pair 作为表示，同样借助模拟退火进行优化。由于这类算法的运行时间会随着问题规模迅速增长，因此无法直接应用于大规模平面规划。为解决这一问题，研究者提出了带有启发式搜索的多层次框架。

多层次启发式方法的核心思想是通过聚类或划分，多层次地缩小解空间，从而处理大规模问题。基于聚类的方法（如 MB*-tree [12]）自底向上合并模块，直到模块数量足够小再进行求解，然后在逐层解聚类过程中不断细化解。它的缺点是：在早期聚类阶段，模块无法从全局角度被合理聚类，因此会限制解质量。

相比之下，基于划分的方法会把原始大规模平面规划问题递归分解为多个足够小的子问题，分别求解后再逐层合并和优化。Capo [13]、DeFer [14]、IMF [15] 和 QinFer [16] 是该方向的代表方法。大多数此类方法使用 hMetis [17] 完成划分。与聚类方法相比，划分方法能够在早期考虑线长信息，但在划分阶段仍然无法精确计算线长。

由于平面规划与 VLSI 布局问题在一定程度上相似，许多研究工作开始基于 VLSI 布局框架构建解析平面规划方法，例如 Analytical [18]、AR [19]、UFO [20] 和 F-FM [1] 等。一般而言，这类方法包含两个阶段：全局平面规划阶段，用于确定模块的大致位置；合法化阶段，用于消除重叠，并确定所有模块的精确位置以及软模块的宽度。结合多层次框架后，这类解析方法也能够处理大规模平面规划。

表 2 总结了这些解析平面规划方法的全局平面规划阶段与合法化阶段。

| 方法 | 全局平面规划 | 合法化 |
| --- | --- | --- |
| Analytical [18] | bell-shaped smoothing 与 density control function | Parquet-4 [11] 中的 `pl2sp()` |
| F-FM [1] | 基于 NTUplace [21] 的布局模型 | 基于位置和面积的渐进式划分 + ST-Tree [22] |
| 文献 [2] | 基于 NTUplace [21] 的布局模型 | SAINT [23] |
| AR [19] | Attractor-Repeller 模型 | 基于相对位置矩阵的 SOCP |
| UFO [20] | Push-Pull 模型 | 基于约束图的 SOCP |

Analytical [18]、F-FM [1] 和文献 [2] 在全局平面规划阶段都采用密度控制。Analytical [18] 根据模块当前位置和宽度计算单元密度，并把软模块当作硬模块处理，然后通过 bell-shaped 函数对密度进行平滑。在合法化阶段，它借助 Parquet-4 [11] 中的 `pl2sp()` 去除重叠。

类似地，F-FM [1] 与文献 [2] 也把所有软模块当成硬模块，并使用全局布局完成全局平面规划。F-FM [1] 在合法化阶段先使用基于模块位置和面积的渐进划分，再借助 ST-tree [22] 和模拟退火来优化模块位置与软模块宽度。文献 [2] 则使用 SAINT [23] 做合法化，其核心思路是用多边形逼近每个软模块的面积曲线，并建立 ILP 模型完成合法化。

更早的 AR [19] 与 UFO [20] 则直接把硬模块和软模块都视为正方形，再进一步抽象为圆形，并分别提出 Attractor-Repeller 与 Push-Pull 模型用于全局平面规划。两者都在合法化阶段采用二阶锥规划（SOCP）求得合法解。区别在于 AR 使用相对位置矩阵，而 UFO 使用约束图。需要指出的是，当问题规模达到中等或较大时，求解 SOCP 会非常耗时。

需要注意的是，平面规划问题同时包含硬模块和软模块，但当前先进的 Analytical [18]、F-FM [1] 与文献 [2] 在全局平面规划时都把软模块当成硬模块处理；此外，它们还必须结合多层次框架才能处理大规模问题。这两点都会影响解质量。

本文聚焦于基础的固定轮廓平面规划问题，因为处理复杂约束的平面规划算法通常都建立在基础平面规划算法之上。值得注意的是，基于泊松方程的 VLSI 全局布局方法 [24][25] 在不使用多层次框架的情况下，依然能够取得当前先进结果。本文的目标，就是把这类方法扩展到同时包含硬模块与软模块的大规模固定轮廓平面规划中，从而构建一个高性能平面规划引擎。

为此，我们不仅要在全局平面规划阶段优化软模块形状，还要相应设计高性能的合法化算法。本文贡献如下：

1. 提出一种新的数学模型来刻画模块间不重叠性。在静电系统思想 [24] 下，基于泊松方程解析解 [25] 重新定义模块势能，使软模块宽度能够作为固定轮廓全局平面规划模型中的变量出现，并且能够方便地求出关于软模块宽度的导数。
2. 给出势能偏导数的快速近似计算方案，并设计基于泊松方程全局布局方法的固定轮廓全局平面规划算法。
3. 通过定义水平与垂直约束图，提出一种快速合法化算法，用于去除全局平面规划之后残留的模块重叠。该算法通过修改模块间相对位置，并压缩平面规划来得到最终合法解。
4. 在可接受运行时间内，本文平面规划算法在大规模基准上取得了更好的结果：与当前先进的多层次启发式搜索算法相比，平均线长至少降低 5%；与当前先进的解析平面规划算法相比，平均线长至少降低 8%。在小规模基准上也有类似改善。

## 2. 预备知识

本节给出固定轮廓平面规划问题定义，介绍线长模型，以及基于泊松方程处理 VLSI 全局布局中模块重叠的基本原理。

### 2.1 固定轮廓平面规划问题

平面规划区域是一个与坐标轴平行的矩形，左下角为原点，右上角为 `(W, H)`。设 `V = Vs ∪ Vh` 为矩形模块集合，其中 `Vs` 和 `Vh` 分别表示软模块集合与硬模块集合。对每个模块 `vi ∈ V`，其宽、高、面积以及中心坐标分别记为 `wi`、`hi`、`Ai` 与 `(xi, yi)`。对每个软模块 `vi ∈ Vs`，其高宽比 `hi / wi` 受上下界 `ARi^l` 与 `ARi^u` 约束。

设 `E` 为网络集合，`WL(ei)` 表示网络 `ei` 的半周长线长（HPWL），`WL(E) = Σei∈E WL(ei)`。则固定轮廓平面规划可表示为：

```text
min WL(E)
s.t. overlap = 0
     aspect ratio is suitable
     all modules are within the fixed-outline
```

本文将目标函数中的线长项建模为 LSE（Log-Sum-Exp）线长函数。三个约束分别表示：

1. 所有模块之间不能重叠；
2. 每个软模块的高宽比满足上下界约束；
3. 所有模块都必须位于固定轮廓内部。

### 2.2 基于泊松方程的 VLSI 全局布局

ePlace [24] 是一种具有代表性的 VLSI 全局布局方法。在 ePlace 中，每个模块 `vi` 被视为带正电的粒子，其电荷量 `qi` 与模块面积 `Ai` 成正比。这样，布局问题被建模为一个二维静电系统，其中电势 `ψ(x, y)` 与电场 `ξ(x, y)` 满足：

```text
ξ(x, y) = (ξx, ξy) = -∇ψ(x, y)
```

ePlace [24] 将 `ψ(x, y)` 定义为以下泊松方程的解：

```text
∇²ψ(x, y) = -ρ(x, y),     (x, y) ∈ R
n̂ · ∇ψ(x, y) = 0,         (x, y) ∈ ∂R
∬R ρ(x, y) dxdy = ∬R ψ(x, y) dxdy = 0
```

其中 `R` 是矩形布局区域，`ρ(x, y)` 是电荷密度函数；第二式为 Neumann 边界条件，`∂R` 为区域边界，`n̂` 为边界外法向量；第三式是兼容条件，用于保证方程解的唯一性。

电力 `Fi = qi ξ(xi, yi)` 会推动模块移动，从而减小模块重叠。定义系统总势能：

```text
N(V) = Σvi∈V N(vi),    N(vi) = qi ψ(vi)
```

根据 ePlace [24]，`overlap = 0` 的必要条件之一是系统势能 `N(V)` 取到最小。因此，可以用 `N(V)` 作为正则项，把 VLSI 全局布局写为：

```text
min LSE(E) + λN(V)
s.t. all modules are in the placement area
```

文献 [25] 将密度函数定义为：

```text
ρ(x, y) = Σvi∈V ρi(x, y),    (x, y) ∈ [0, W] × [0, H]
ρi(x, y) = 1,  if (x, y) ∈ Ri
          0,  else
```

其中

```text
Ri = [xi - wi/2, xi + wi/2] × [yi - hi/2, yi + hi/2],   hi = Ai / wi
```

再通过

```text
ρ(x, y) := ρ(x, y) - (1 / WH) ∬R ρ(x, y) dxdy
```

可得到泊松方程的解析解。其截断形式为：

```text
ψ(x, y) = Σu=0..K Σp=0..K aup cos(uπx/W) cos(pπy/H)
```

其中 `K` 为控制精度的截断因子。

为加速全局布局，文献 [25] 假设布局区域被划分为 `K × K` 个 bin，每个网格的密度为：

```text
ρ̂(i, j) = Σvk∈V Area(bin(i,j) ∩ Rk) / Area(bin(i,j))
```

经类似重定义后，泊松方程在网格中心点 `(i+1/2, j+1/2)` 处的截断解析解为：

```text
ψ̂(i, j) = Σu,p=0..K-1 aup cos(u(i+1/2)π/K) cos(p(j+1/2)π/K)
```

## 3. 全局平面规划模型与梯度计算

本文将固定轮廓平面规划分为两个阶段：全局平面规划与合法化。全局平面规划允许模块之间存在少量重叠，用来构造一个“粗略”的平面规划；合法化阶段则消除重叠，得到最终合法解。

为了能在全局平面规划阶段优化软模块形状，本文首先提出模块不重叠的数学刻画，再在此基础上修改 VLSI 全局布局模型。

### 3.1 全局平面规划模型

首先，本文给出模块不重叠的充要条件。

**引理 1**：任意两个不同模块 `vi` 和 `vj ∈ V` 不重叠，当且仅当：

```text
∬Ri ρj(u, v) dudv = 0
```

**引理 2**：对任意模块 `vi ∈ V`，有：

```text
∬Ri ρi(u, v) dudv = Area(Ri)
```

**定理 1**：模块 `vi ∈ V` 与其它模块均不重叠，当且仅当：

```text
∬Ri Σvj∈V ρj(u, v) dudv = Area(Ri)          (8)
```

根据引理 2 与定理 1，可知：

```text
∬Ri Σvj∈V ρj(u, v) dudv ≥ Area(Ri)
```

于是，式 (1) 中的不重叠约束可等价改写为式 (8)。借助机器学习中的正则化技术 [26]，固定轮廓平面规划问题可转化为：

```text
min WL(E) + λ Σvi∈V ∬Ri Σvj∈V ρj(u, v) dudv
s.t. aspect ratio is suitable
     all modules are within the fixed-outline            (9)
```

在模型 (9) 中，`Σvj∈V ρj(u, v)` 可被理解为平面规划区域内的密度函数。为了便于优化，VLSI 全局布局通常采用以下三种方法来松弛密度函数：

1. 将区域划分为 bins，用 bell-shaped 函数平滑密度，再积分；
2. 将区域划分为 bins，用泊松方程平滑密度，再积分；
3. 直接对 `Σvj∈V ρj(u, v)` 积分。

本文采用方案 2，因为泊松方程方法在 VLSI 全局布局中已经取得了当前先进结果。

设 `ψ(u, v)` 是对密度函数 `Σvj∈V ρj(u, v)` 进行平滑后的泊松方程解，则对每个模块 `vi ∈ V`，定义其势能：

```text
Ni = ∬Ri ψ(u, v) dudv                                  (10)
```

其中 `Ri = [xi - wi/2, xi + wi/2] × [yi - hi/2, yi + hi/2]`，`hi = Ai / wi`。

于是：

```text
gi(xi, yi, wi) = Ni = ∬Ri ψ(u, v) dudv,   ∀vi ∈ Vs
gi(xi, yi)     = Ni = ∬Ri ψ(u, v) dudv,   ∀vi ∈ Vh      (11)
```

由此建立全局平面规划模型：

```text
minx,y,w LSE(E) + λ [ Σvi∈Vs gi(xi, yi, wi) + Σvi∈Vh gi(xi, yi) ]   (12a)
s.t. ARi^l ≤ Ai / wi^2 ≤ ARi^u,    ∀vi ∈ Vs                          (12b)
     wi/2 ≤ xi ≤ W - wi/2,         ∀vi ∈ V                           (12c)
     hi/2 ≤ yi ≤ H - hi/2,         ∀vi ∈ V                           (12d)
```

其中，约束 (12b) 保证软模块高宽比合法，(12c) 与 (12d) 保证所有模块位于平面规划区域内部。

### 3.2 势能偏导数

为了使用非线性优化方法求解问题 (12)，需要计算目标函数对每个变量的偏导数。LSE 线长函数本身是解析形式，因此其偏导较易计算。难点在于势能项。

将泊松方程的解析解代入式 (11) 并进行积分，可得到软模块势能函数 `gi(xi, yi, wi)` 的展开式（原文式 (13)）。进一步分别对 `xi`、`yi` 和 `wi` 求偏导，可得到原文式 (14)、(15)、(16)。

当各系数已知时，对单个模块而言，计算其关于 `xi`、`yi`、`wi` 三个变量偏导的时间复杂度均为 `O(K^2)`，其中 `K` 是式 (5) 中控制精度的截断常数。因此，对全部 `n` 个模块计算偏导的复杂度为 `O(nK^2)`。虽然它关于模块数 `n` 是线性的，但实验表明常数 `K^2` 很大，求解大规模问题时仍然耗时较长。

### 3.3 势能偏导数的快速近似计算

由式 (6) 和式 (7)，平面规划区域 `[0, W] × [0, H]` 被离散为 `K × K` 个 bins，每个 bin 的宽、高分别为：

```text
wb = W / K,    hb = H / K
```

设 `Ri` 为模块 `vi` 所占据的矩形区域，`Bvi` 为与 `Ri` 相交的 bins 集合。作者定义了两个辅助函数来求覆盖 `Ri` 的最小 bin 集：

```text
up(x)   = 0,        if x = 0
          ceil(x)-1, if x > 0

down(x) = floor(x),  x ≥ 0                              (17)
```

据此可得到 `Bvi` 的左右上下边界 `Xi^L`、`Xi^U`、`Yi^L`、`Yi^U`。然后基于数值积分中的矩形法则，可将式 (11) 中的积分近似为对 `Bvi` 上网格电势 `ψ̂(p, q)` 的加权求和。

在这个近似下，原文式 (18)、(19)、(20) 分别给出了：

1. `∂gi(xi, yi, wi) / ∂wi` 的近似表达；
2. `∂gi(xi, yi, wi) / ∂xi` 的近似表达；
3. `∂gi(xi, yi, wi) / ∂yi` 的近似表达。

当所有 `ψ̂(p, q)` 都已计算完成时，这三个偏导的计算代价与 `(Xi^U - Xi^L) + (Yi^U - Yi^L)` 成线性关系。因此，对所有模块计算偏导的复杂度为：

```text
O(K^2 log K) + O(n * AVG / n)
```

其中，第一项来自两次 FFT：一次计算系数 `aup`，一次计算所有 `ψ̂(p, q)`；第二项来自按模块遍历其所覆盖的少量网格边界。作者指出，这里的平均网格占用数 `AVG / n` 远小于总网格数 `K^2`，因此加速后的偏导计算在保持关于模块数线性的同时，大幅降低了常数项开销。

文中把第 3.2 节的精确偏导计算称为 **PDBA**（加速前偏导计算方法），把本节方法称为 **加速偏导计算方法**。

## 4. 固定轮廓平面规划算法

本文算法框架如原文图 2 所示，共包含三个阶段：

1. 初始平面规划；
2. 全局平面规划；
3. 合法化。

初始解直接采用 ePlace [24] 中的 QP 方法生成。本文重点介绍后两个阶段。

### 4.1 全局平面规划算法

在图 2 的全局平面规划阶段中，密度计算、泊松方程求解、势能计算、`x/y` 方向偏导、`w` 方向偏导以及线长梯度计算，都已在第 3 节给出。其余流程见原文算法 1。

**算法 1：全局平面规划**

输入：初始解 `u0 = (x0, y0, w0)`、`λ0`、最大迭代次数 `kmax`、最小重叠阈值 `Omin`

输出：全局平面规划解 `ugp`

1. 对 `k = 0 .. kmax`：
2. 构造第 `k` 次迭代的目标函数  
   `fk = LSE(E) + λk [ Σvi∈Vs gi(xi, yi, wi) + Σvi∈Vh gi(xi, yi) ]`
3. 计算 `fk` 关于 `x`、`y`、`w` 的偏导；
4. 固定软模块宽度，调用 Nesterov 方法优化模块位置 `(xk+1, yk+1)`；
5. 固定模块位置，使用归一化梯度下降更新软模块宽度 `wk+1`；
6. 得到 `uk+1 = (xk+1, yk+1, wk+1)`；
7. 将 `uk+1` 投影到可行域；
8. 计算当前重叠 `Ok+1` 并更新罚参数 `λk+1`；
9. 若 `Ok+1 <= Omin`，则停止；
10. 返回 `ugp`。

这里，模块位置优化使用 Nesterov 一阶方法，其收敛率为 `O(1/k^2)`。作者设置 `a0 = 1`、`u0 = v0`，其中 `v0` 为初始平面规划给出的解。

**算法 2：Nesterov-Solver**

输入：主解 `uk`、参考解 `vk`、优化参数 `ak`、目标函数 `fk = f(vk)`

输出：`uk+1`、`vk+1`

1. 计算 `x/y` 方向梯度 `∇x,y fk(vk)`；
2. 用回溯线搜索求步长 `ak`；
3. 更新新解 `uk+1 = vk - ak ∇x,y fk`；
4. 更新参数  
   `ak+1 = (1 + sqrt(4ak^2 + 1)) / 2`
5. 更新参考解  
   `vk+1 = uk+1 + ((ak - 1) / ak+1) (uk+1 - uk)`
6. 返回。

在 Nesterov 过程中，作者与 ePlace [24] 一样使用 Jacobi 预条件器来提升收敛速度和解质量。

第 5 步使用归一化梯度下降来优化软模块宽度。固定位置后，计算 `∇w fk`，并设置：

```text
uk+1 = uk - step * ∇w fk,   step = a / ||∇w fk||,   a = 1
```

需要注意的是，软模块宽度变化会影响引脚位置，因此在下次调用 Nesterov-Solver 前，需要按比例更新引脚坐标。

由于 `uk+1` 不一定满足问题 (12) 的约束，因此算法会将其投影回可行域。

对软模块宽度，投影规则为：

```text
wi = sqrt(Ai / ARi^l),   if Ai / wi^2 < ARi^l
wi = sqrt(Ai / ARi^u),   if Ai / wi^2 > ARi^u
wi = wi,                 otherwise
```

对模块位置，投影规则为：

```text
xi = wi/2,       if xi < wi/2
xi = W - wi/2,   if xi > W - wi/2
xi = xi,         otherwise

yi = hi/2,       if yi < hi/2
yi = H - hi/2,   if yi > H - hi/2
yi = yi,         otherwise
```

罚参数 `λ` 的更新方式与 ePlace [24] 相同。首先设定每次迭代期望的线长变化 `ΔHPWLref`，然后：

```text
λk+1 = μk λk
μk = μ0^(-ΔHPWLk / ΔHPWLref + 1)
ΔHPWLk = HPWL(vk) - HPWL(vk-1)
```

其中 `μ0 = 1.1`，`μk` 通常截断在区间 `[0.75, 1.1]` 内。

### 4.2 合法化

全局平面规划之后，可得到一个只有少量重叠的“粗略”平面规划。合法化阶段的目标，就是消除这些残留重叠，使其满足无重叠约束。

在合法化阶段，作者将全局平面规划结果作为初始解，并把所有软模块都暂时视为硬模块。如果问题规模较小，则直接使用 Parquet [11] 中的 `pl2sp`；否则，使用本文提出的方法。

Abacus [27]、SAINT [23] 和 Floorist [28] 是当前有代表性的合法化方法。Abacus 主要面向标准单元布局，依赖行对齐，因此不适合高度差异很大的固定轮廓平面规划；SAINT 通过多边形逼近面积曲线并求解 ILP，较难扩展到大规模问题；Floorist [28] 则更接近平面规划修复方法。

本文合法化算法基于 Floorist [28]，但与之有一个关键区别：

1. Floorist 会在约束图中插入约束，使模块最终不重叠，但不会删除约束；
2. 插入过程中固定轮廓可能满足，但无重叠条件可能被破坏，且约束图最终会很稠密；
3. 本文方法既插入约束，也删除约束；
4. 本文始终保证无重叠条件成立，但允许临时违反固定轮廓约束，最后再通过修改约束图满足固定轮廓。

#### 4.2.1 水平/垂直约束图及相关定义

作者根据全局平面规划后模块的相对位置关系，构造水平约束图 `HCG` 与垂直约束图 `VCG`。

设模块 `A` 的左下角坐标不大于模块 `B` 的左下角坐标，则有三种情况：

1. 若 `A` 与 `B` 在水平方向和垂直方向都不重叠，则在 `VCG` 中加入 `A ↑ B`，在 `HCG` 中加入 `A → B`；
2. 若两者垂直方向重叠、但水平方向不重叠，则在 `HCG` 中加入 `A → B`；
3. 若两者在两个方向上都重叠，则比较水平重叠量与垂直重叠量：若水平重叠更大，则在 `VCG` 中加入 `A ↑ B`；否则在 `HCG` 中加入 `A → B`。

合法化的总体策略是：在水平与垂直方向交替进行压缩和关系调整。以水平合法化为例，算法会删除 `HCG` 中两个模块之间的一条边，再在 `VCG` 中添加一条对应边，然后重新压缩平面规划。垂直合法化完全类似。

当不存在矛盾时，边可以被任意增删；同时，也不需要显式维护 `HCG` 和 `VCG` 的传递闭包，以减少边数。真正的关键在于：选择哪一条边进行调整。

在水平合法化中，算法倾向于选择对 `VCG` 影响最小的边，这通过比较 `HCG` 中边的权重来实现；垂直合法化则对 `VCG` 做同样的处理。

根据 `HCG`，先在保持 `HCG` 不变的前提下，尽可能把模块向左压缩。模块 `A` 左下角的横坐标为：

```text
xA = maxB(B→A) (xB + wB),   if 存在 B→A
xA = 0,                     otherwise                    (21)
```

类似地，可以求出模块 `A` 左下角的纵坐标 `yA`。于是所有模块将变为互不重叠。

设 `noRight = {A | ∀B, A ↛ B}`，则包围所有模块的最小矩形宽度为：

```text
Wd = maxA∈noRight (xA + wA)                               (22)
```

高度 `Hd` 可类似计算。

随后，把坐标原点临时移到 `(Wd, 0)`，并把 `x` 轴正方向改为向左。在这个临时坐标系中构造新的水平约束图 `HCG'`，并重新计算每个模块的横向压缩位置 `xA'`。于是定义模块 `A` 的水平松弛量：

```text
SxA = W - (xA + xA' + wA)                                 (23)
```

类似地可定义垂直松弛量 `SyA`。

若 `SxA = 0` 且 `SxB = 0`，则称水平关系 `A → B` 是**关键关系**；若 `SyA = 0` 且 `SyB = 0`，则称垂直关系 `A ↑ B` 是关键关系。

进一步，定义水平可压缩关系：若 `A → B` 且区间 `[yA, yA+hA]` 与 `[yB, yB+hB]` 不相交，则记为 `A ∩y B = ∅`。这意味着可以在保持不重叠的同时，进一步沿水平方向压缩布局。垂直可压缩关系 `A ∩x B = ∅` 定义类似。

对于水平关键关系 `A → B`，定义其权重：

```text
Weight(A → B) =
    SyA - hB,   if yA ≤ yB
    SyB - hA,   otherwise                                  (24)
```

这个权重的作用是：当需要从 `HCG` 删除一条边并在 `VCG` 中加入一条新边时，优先选择对包围矩形高度 `Hd` 增长最小的关系进行修改。

#### 4.2.2 合法化算法

**算法 3：合法化总流程**

输入：平面规划区域宽高 `(W, H)`、水平与垂直约束图 `(HCG, VCG)`、最大迭代次数 `N`

输出：每个模块左下角坐标 `(x̂A, ŷA)`

1. 对 `i = 1 .. N`：
2. `(HCG, VCG) = LGx(W, HCG, VCG)`；
3. `(HCG, VCG) = LGy(H, HCG, VCG)`；
4. 根据当前 `(HCG, VCG)` 计算包围所有模块的最小矩形 `(Wd, Hd)`；
5. 若 `Wd <= W` 且 `Hd <= H`，则停止；
6. 返回 `(x̂A, ŷA)`。

算法 3 在水平和垂直方向交替合法化。若某轮迭代后包围矩形已经完全落入固定轮廓中，则退出。

**算法 4：水平方向合法化 `LGx(W, HCG, VCG)`**

输入：平面规划区域宽度 `W`、当前 `(HCG, VCG)`

输出：更新后的 `(HCG, VCG)`

1. 根据当前 `(HCG, VCG)` 计算所有模块的 `(xA, yA)`、`(SxA, SyA)` 以及 `Wd`；
2. 当 `Wd > W` 时循环：
3. 令 `S = {A → B ∈ HCG | SxA = 0 且 SxB = 0}` 为水平关键关系集合；
4. 若存在 `(A → B) ∈ S` 且 `A ∩y B = ∅`；
5. 则从 `HCG` 中删除关系 `A → B`；
6. 否则：
7. 对所有 `(A → B) ∈ S` 计算 `Weight(A → B)`；
8. 找到权重最大的 `(A → B)`；
9. 从 `HCG` 删除该边；
10. 若 `yA ≤ yB`，则在 `VCG` 中加入 `A ↑ B`；
11. 否则在 `VCG` 中加入 `B ↑ A`；
12. 重新执行第 1 步；
13. 返回 `(HCG, VCG)`。

根据拓扑排序以及式 (21)、(22)、(23)，算法 4 中步骤 1 与步骤 12 的时间复杂度为 `O(|E| + |V|)`。由于关键关系集合 `S` 满足 `|S| <= |E|`，其余关键操作也都为 `O(|E|)`，因此算法 4 每轮迭代的时间复杂度为 `O(|E| + |V|)`。

#### 4.2.3 水平合法化示例

为了说明合法化算法的有效性，作者将其应用到 XDP [29] 的一个示例上。原文图 4(a) 给出了带重叠的模块分布，图 5(a) 给出了对应的 `HCG`。

先根据当前 `HCG` 与 `VCG` 压缩得到无重叠布局，如图 4(b)。若此时 `Wd > W`，则说明虽然已经无重叠，但仍超出固定轮廓，需要继续做水平方向合法化。算法先提取关键关系；如果不存在可直接压缩的关系，则根据式 (24) 计算边权并选取合适的边删除，再在 `VCG` 中插入对应的新边。经过若干轮迭代后，可得到图 4(c) 所示的合法布局。

## 5. 实验结果

本文在 MCNC [30]、GSRC [31]、HB+ [32] 和 ami49 x [12][15] 基准上，将所提固定轮廓平面规划算法与当前先进方法进行了比较。算法使用 C++ 实现，运行环境为 Linux，处理器为 3.60GHz Intel Core i3-9100，内存 4GB。本文关注同时含有硬模块和软模块的平面规划。所有比较中的线长都采用 HPWL 度量，比较数据直接引用相关文献。

实验参数如下：

1. 算法 1 中 `kmax = 1200`；
2. `Omin` 约设为 `1%`；
3. 算法 3 中 `N = 10`。

### 5.1 MCNC 与 GSRC 基准

这些基准包括 `ami33`、`ami49`、`n100`、`n200` 和 `n300`，模块数分别为 33、49、100、200 和 300，且全部都是软模块。

作者进行了两组实验。

第一组实验：固定空白率为 15%，把平面规划区域高宽比从 `1:1` 改为 `4:1`，用于测试算法对不同高宽比的适应性。

第二组实验：将空白率降为 10%，固定高宽比为 `1:1`。两组实验都设置全部软模块满足：

```text
1/3 = ARi^l ≤ hi / wi ≤ ARi^u = 3
```

在第一组实验中，作者将本文算法（使用加速偏导计算方法的版本，即后文的 `ours`）与 Analytical [18] 以及基于模拟退火的 Parquet-4 [11] 比较。三者都未使用多层次框架。所有基准的 I/O pads 均保持原始位置。

原文表 3 的结论是：在不同高宽比下，本文算法的平均 HPWL 至少比 Analytical [18] 低 16%，至少比 Parquet-4 [11] 低 31%。

在第二组实验中，每个基准的高宽比固定为 `γ = 1`，并将 I/O pads 移到平面规划区域边界。对比算法包括：

1. 解析方法 AR [19] 与文献 [2]；
2. 基于多层次框架的 Capo 10.2 [13]、IMF [15]、IMF+AFF [12]；
3. 基于模拟退火的 DeFer [14] 与 Parquet-4 [11]。

原文表 4 的结论是：平均而言，本文算法的 HPWL 比 DeFer [14] 低 6%，比 IMF [15] 低 6%，比 IMF+AFF [12] 低 7%，比 Capo 10.2 [13] 低 13%，比 Parquet-4 [11] 低 29%。与解析算法文献 [2] 和 AR [19] 相比，也分别低 2% 和 5%。

### 5.2 HB+ 基准

HB+ 基准是在 HB 基准基础上构造得到：把最大的硬宏面积扩大 100%，再缩减其余软宏面积，以保持总单元面积不变。因此，这组基准非常困难。

本文将算法与以下方法比较：

1. DeFer [14]；
2. QinFer [16]；
3. 文献 [2] 的解析平面规划器。

由于本文有两种势能偏导计算方式，因此也对应两种实现：

1. `ours PDBA`：使用第 3.2 节的加速前偏导计算；
2. `ours`：使用第 3.3 节的加速偏导计算。

原文表 5 给出了详细比较。其主要结论如下：

1. 在平均 HPWL 上，`ours` 比 QinFer 低 5%，比 DeFer 低 8%，比文献 [2] 低 8%；
2. 在运行时间方面，DeFer 与 QinFer 平均分别约为本文算法的 89% 和 123%，而文献 [2] 的运行时间显著更长；
3. 对于小规模基准（表 4），本文算法和文献 [2] 都不使用多层次框架，本文平均比其好 2%；对于大规模 HB+ 基准，本文依然保持扁平化，而文献 [2] 则使用多层次框架，此时本文平均好 8%。作者据此认为：进一步改进的重要原因正是本文算法是扁平化的，不依赖多层次框架。

一个有意思的实验现象是：理论上，精确偏导的 `ours PDBA` 应该优于近似偏导的 `ours`；但表 5 显示 `ours PDBA` 的平均 HPWL 反而比 `ours` 略高 2%。作者解释说，这是因为固定轮廓平面规划是非凸优化问题，目标函数存在多个局部极小值。沿“精确梯度”下降并不一定就能找到更优解，而近似偏导带来的误差，反而给算法提供了有限的跳出局部最优的能力。

### 5.3 ami49 x 基准

为测试算法在超大规模固定轮廓平面规划上的表现，作者使用了 ami49 x 基准 [12][15]。其构造方式为：

1. 将每个模块 `vi` 与每条网络复制 `x` 次，得到 `vi,1 ... vi,x`；
2. 再加入 `x-1` 条网络 `(vi,1, vi,2)`、`(vi,1, vi,3)` ... `(vi,1, vi,x)`；
3. 最后把每个模块的宽和高都缩小 5 倍，以避免计算线长时发生溢出。

该实验中，空白率设为 15%，平面规划区域高宽比 `γ = 1`，I/O pads 被移动到边界上。

原文表 6 给出了与 Capo 10.2 [13]、MB*-tree [15] 和 IMF+AFF [12] 的比较结果。其平均结论是：

1. 本文算法的平均 HPWL 比 Capo 10.2 低 7%；
2. 比 IMF+AFF 低 10%；
3. 比 MB*-tree 低 58%。

在运行时间方面，虽然比较方法使用的硬件环境不同，不能直接严格比较，但本文算法能够在不超过 5 分钟内完成多达 9800 个模块的实例，而对比算法至少需要 19 分钟，因此作者认为其运行时间是可接受的。

接下来，作者分析了采用加速偏导计算时的运行时间构成。

总运行时间由三部分组成：

1. 用 QP 生成初始解的时间；
2. 全局平面规划时间；
3. 合法化时间。

原文图 7 给出了 HB+ 全部基准上的时间占比。平均而言：

1. 初始解生成约占 `9.4%`；
2. 全局平面规划约占 `80.2%`；
3. 合法化约占 `10.4%`。

因此，全局平面规划是本文算法中最耗时的部分。

原文图 8 进一步展示了单次全局平面规划迭代的平均时间随问题规模变化的趋势。无论是使用精确偏导还是近似偏导，单次迭代时间都与问题规模近似线性相关；但加速偏导方法明显更快。

### 5.5 全局平面规划与合法化的衔接效果

最后，作者分析了全局平面规划结束后的重叠率，以及合法化前后线长的变化。

原文表 7 的结论是：

1. 全局平面规划之后，平均重叠率仅为 `0.96%`；
2. 合法化之后，平均 HPWL 反而下降了 `0.34%`。

作者解释说，线长下降来自合法化过程中的布局压缩。与此同时，合法化前后线长变化总体不大，这说明本文合法化算法本质上是一种局部修改算法，并不会大幅破坏全局平面规划阶段得到的结果。

## 6. 结论

本文基于一种新的模块不重叠数学模型和泊松方程的解析解，提出了一种不依赖多层次框架的固定轮廓平面规划算法。该算法由全局平面规划和合法化两个阶段组成。

在全局平面规划阶段，算法利用重新定义的势能来实现模块扩散，并同时优化软模块宽度；在合法化阶段，算法利用约束图在水平和垂直两个方向交替消除重叠。MCNC、GSRC、HB+ 与 ami49 x 基准实验表明：在可接受运行时间内，本文算法在小规模和大规模基准上得到的平均 HPWL 分别至少比已有先进方法低 2% 和 5%。

作者最后指出：把布线可达性、时序、热效应等问题进一步纳入该平面规划算法，是后续正在进行的工作。

## 附录

### 引理 1

任意两个不同模块 `vi` 和 `vj ∈ V` 不重叠，当且仅当：

```text
∬Ri ρj(u, v) dudv = 0
```

**证明**：由于 `ρj(u, v) ≥ 0`，所以 `∬Ri ρj(u, v) dudv = 0` 等价于对所有 `(u, v) ∈ Ri` 都有 `ρj(u, v) = 0`。这又等价于 `Ri ∩ Rj = ∅`，即模块 `vi` 与 `vj` 不重叠。

### 引理 2

对任意模块 `vi ∈ V`，有：

```text
∬Ri ρi(u, v) dudv = Area(Ri)
```

**证明**：根据 `ρi(u, v)` 的定义，在 `Ri` 内恒有 `ρi(u, v) = 1`，因此：

```text
∬Ri ρi(u, v) dudv = ∬Ri 1 dudv = Area(Ri)
```

### 定理 1

模块 `vi ∈ V` 与其它所有模块不重叠，当且仅当：

```text
∬Ri Σvj∈V ρj(u, v) dudv = Area(Ri)                      (25)
```

**证明**：

若模块 `vi` 与其它模块都不重叠，则根据引理 1 与引理 2：

```text
∬Ri Σvj∈V ρj(u, v) dudv
= Σvj∈V ∬Ri ρj(u, v) dudv
= ∬Ri ρi(u, v) dudv + Σvj∈V, vj≠vi ∬Ri ρj(u, v) dudv
= Area(Ri) + 0
= Area(Ri)
```

反过来，若式 (25) 成立，则有：

```text
Area(Ri)
= ∬Ri Σvj∈V ρj(u, v) dudv
= ∬Ri ρi(u, v) dudv + Σvj∈V, vj≠vi ∬Ri ρj(u, v) dudv
= Area(Ri) + Σvj∈V, vj≠vi ∬Ri ρj(u, v) dudv
```

其中最后一步利用了引理 2。因此：

```text
Σvj∈V, vj≠vi ∬Ri ρj(u, v) dudv = 0
```

又由于 `ρj(u, v) ≥ 0`，上式推出对所有 `vj ≠ vi` 都有：

```text
∬Ri ρj(u, v) dudv = 0
```

再由引理 1 可知，`vi` 与所有其它模块均不重叠，定理得证。
